## 1. Форматы строк (кратко)

Враги (основной):
  X,Y,EnemyType,Count[,описание]
  X,Y,EnemyType|faction=<id>|ec_event=<eventId>,Count
  X,Y,POOL[TypeA,TypeB],Count
  RANDOM,chance,X,Y,EnemyType,Count
  RANDOM_GROUP,N,START ... END

Якоря EventCore (не враги — отдельные драйверы):
  EVENTTRAP,<packFolder>,<x>,<y>
  REINFORCEMENT,<packFolder>,<x>,<y>
  Шпаргалка: EVENT_TRAP_SPAWN_CHEATSHEET.txt

Визуальные шаблоны сцены (ловушки-пропы, не EventTrap-логика):
  TRAP,<Key>,<x>,<y>,<Count>
  OBJECT,<Key>,<x>,<y>,<Count>
  SPAWN,Trap|<Object>,<Key>,<x>,<y>,<Count>

## 4. Фракции (pipe |faction=)

Основные id (CombatAi/Factions.json):

  bandits              — бандиты (база)
  bandits_inquisition  — бандиты + церковь (подфракция)
  bandits_mafia        — бандиты + мафия
  bandits_demons       — бандиты + демоны
  church               — инквизиция
  mafia                — мафия
  demons               — демоны
  undead               — нежить
  monsters             — монстры

Пример:
  -90.0,-120.0,TouzokuNormal|faction=bandits,2
  -90.0,-120.0,Inquisition|faction=church,1

EventCore-NPC (пассив до резолва события):
  |faction=eventcore_encounter


## 5. EventCore — модальные события (|ec_event=)

Включить: [EventCore] Enable = true
Активны в eventcore_manifest.json:

  eventcore_broker_gate           — брокер (пошлина 500g / переговоры / засада 4N+4Axe)
  eventcore_fsp_bandits_sex_paid  — FSP бандиты, платный секс (MB + репутация bandits; consent grab)

Примеры:
  623.54,-286.95,TouzokuNormal|ec_event=eventcore_broker_gate,1
  -118.0,-135.0,TouzokuNormal|ec_event=eventcore_fsp_bandits_sex_paid,1
  620.0,-287.0,TouzokuNormal|ec_pool=eventcore_broker_gate,eventcore_fsp_bandits_sex_paid,1

Сокращение: |ec=<eventId>  (= |ec_event=)

УДАЛЕНО / не использовать:
  eventcore_fsp_bandits_buyher, sharegold, chat, sex_friend


## 6. EventTrap — координатные ловушки (EVENTTRAP)

Реестр: EventCore/event_trap_registry.json
Включить: [EventCore] EventTrapEncountersEnable = true

Разрешённые packFolder (whitelist) — полный список в EVENT_TRAP_SPAWN_CHEATSHEET.txt

  etrap_touzoku_touzokuaxe          — TouzokuNormal/Axe, спавн справа, до 3 волн
  etrap_undead                      — Undead, радиус 12, задержка засады 1 с
  etrap_dorei, etrap_goblin, etrap_kakasi, etrap_mafiabosscustom, etrap_mafia,
  etrap_mutude, etrap_prisonofficer, etrap_slaughterer, etrap_vagrant, etrap_bigonibrother

Пример:
  EVENTTRAP,etrap_touzoku_touzokuaxe,-111.86,-124.50
  EVENTTRAP,etrap_goblin,<X>,<Y>

Мысли Арадии: EventCore/<Lang>/event_trap_gate/phrases.json
Не путать с TRAP,Key,X,Y — там только визуал сцены.


## 7. Reinforcement — KO-засада (REINFORCEMENT)

Реестр: EventCore/reinforcement_registry.json
Включить: [EventCore] ReinforcementEncountersEnable = true

  boss_reinf_touzoku

Пример:
  REINFORCEMENT,boss_reinf_touzoku,1.57,-123.50


## 8. TRAP / OBJECT — шаблоны сцены

Статический список (док): docs/Lore/AVAILABLE_SPAWN_TEMPLATES.txt
Runtime (после preload):  AVAILABLE_SPAWN_TEMPLATES_RUNTIME.txt  ← ключи, что реально в кэше
Авторский с описаниями:   SPAWN_TRAP_OBJECT_CATALOG.txt

Примеры ключей (могут отличаться по сборке):
  BlackOozeTrapTypeB, TrapMachine, TrapSpider, Trap_Rockinghorse, woodwana, trap_hari, …

Пример:
  TRAP,BlackOozeTrapTypeB,100.0,-120.0,1
  OBJECT,woodwana,-100.0,-120.0,1
